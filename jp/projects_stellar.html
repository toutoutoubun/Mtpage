PROJECT / STELLAR

あなたの思考は、
あなたのもの。

論文・ノート・分析ツールを一つのアプリで。

ローカル環境を優先しながら、きちんとクラウドでバックアップ。AI機能なし、サブスク不要。

CORE FEATURES

5つのツール

Library（蔵書管理）
論文や書籍を整理。タグ、分類、検索対応。
Editor（執筆環境）
Markdown + WikiLink。思考を素早く記録。
Citation Network
引用関係を可視化。研究の脈をつかむ。
Qualitative Analysis
テキストデータの分析。コーディング機能。
Export（出版）
PDF、Word、HTMLで出力。どこでも開く。
Local First
ローカル優先。クラウドバックアップ付き。
